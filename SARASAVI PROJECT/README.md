# Sarasavi Offset Printers website

**Start here: [UPGRADE_GUIDE.md](UPGRADE_GUIDE.md)**

This version preserves the homepage and unified navigation while adding quotation requests, an optional artwork upload, local order tracking/admin, gallery filters and an FAQ page.

Run `python server.py` in this folder and open `http://localhost:8000`.

Note: The Python server is for local development. Public hosting needs deployment work and security hardening.
